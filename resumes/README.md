# 📄 Base Resume Directory

Drop your base resume file here!

Supported formats:
* **PDF** (`.pdf`) — e.g. `my_resume.pdf`, `Abdurrahman_Hassan_CV.pdf`
* **JSON** (`.json`) — matching the `CandidateProfile` schema
* **Markdown / Text** (`.md`, `.txt`)

### ⚡ How It Works
1. Place your base resume file (e.g. `resume.pdf`) directly into this `resumes/` folder.
2. The system **automatically detects and parses** your resume on first startup.
3. Every tailored resume and cold email generated in `output/` will automatically be built using your base resume data.
4. If you ever update your resume file, simply replace it in this folder — the system will auto-reload the new version!
